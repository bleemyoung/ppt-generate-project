# 模板驱动 PPT 合成案例

这是一个不含真实企业、项目或经营数据的合成案例，用于向 Agent 展示
`lecture.md → storyboard.md → build.mjs` 的对应关系。

使用边界：

- 只参考文件结构、页面拆分、样式 token、组件函数和来源备注写法。
- 案例文案不是新任务的事实来源，不得复制到正式演示稿。
- 新任务存在明确参考模板时，模板约束优先于本案例的蓝白配色。
- 正式构建从 Skill 的 `assets/build-starter.mjs` 开始，本案例用于补充完整页面写法。

文件：

```text
intermediate/lecture.md
intermediate/storyboard.md
scripts/build.mjs
```
