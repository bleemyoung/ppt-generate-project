# Deck brief

- **Audience:** 内部同事（会制作或维护 PPT 的团队）
- **Purpose:** 复盘一次真实的 AI 辅助 PPT 实践，说明从“一次生成”转向“分阶段可复现”的原因、产出链路、中间层、职责分工、问题修正与取舍结论。
- **Mode:** create
- **Language:** zh-CN
- **Theme:** swiss-grid
- **Expected slides:** 14
- **Image policy:** 无外部图片素材，全部使用原生文字、表格、流程与形状，保持数据/流程导向；不使用截图替代原生内容。
- **Required claims:** 一次生成有确认/追溯/交接短板 → 分阶段链路（报告→原始文本→内容口径→页面决策→脚本→生成→定稿）→ 三个中间层各司其职 → 职责分工降低单点依赖 → 关键规则（不概括过度、同层级一致、回写中间层、生成/定稿分离）→ 分阶段 vs 直接生成对比 → 结论与取舍。
- **Constraints:** 所有可见对象在 PowerPoint 中保持可编辑；正文在 18pt 以上、表格在 15pt 以上；不在可见页脚放来源 ID 或内部路径；流程、职责与对比以原生内容呈现。
- **Source:** `src-01-source`（原始材料 Markdown）。所有内部来源 ID、文件名与路径只进入 `sourceRefs` 与演讲备注，不进入可见页面。
