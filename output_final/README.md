## 维护约定

- 只在本目录保存经过人工确认的 `.final.pptx`，自动生成的 `.generated.pptx` 保存在 `output/`，不要混放。
- 新增终稿时，在上表追加一行，记录日期、文件名、模型、运行环境、实施范围和单次费用。
- 人工修改终稿后，如果还需要重新生成，应将修改同步回对应页面稿和构建脚本。
- 不直接覆盖已有终稿；新版本使用新的日期或序号命名，保留产出历史。
